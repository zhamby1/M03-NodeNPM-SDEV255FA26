# Instructions How To Use Project

To run the project do the following:

1. Download/unzip the project and/or clone it to a local folder

2. Not a bad idea to delete the Node Modules Folder so it can overwrite it

3.  Type in the following command
    ```npm install``` in the terminal

4.  You can either run it by typing in ```node server.js``` or ```nodemon server.js``` if you have nodemon installed globally

5.  You can switch in between each branch to see how each iteration of this project works.

By default the URL for this project is: 127.0.0.1:3000
